How to use this

If you're applying: If you hold a Class 5 or valid driver's license, the Contractor fleet roles and the Operations driver roles are the clearest matches. Many Contractor roles are contracts that require your own 'Vehicle Access' and 'Storage Space', and some require insurance (Columbus: 'commercial auto insurance'). Their pay is often stated as weekly 'earning potential' or 'revenue-share' rather than an hourly wage. The Operations roles list hourly pay, for example $17-19/hour for the Raleigh driver role. Check lifting, licence, language and location requirements in each posting.

If you're selling or recruiting: Note that bird.com describes a communications API business, while these postings are for e-scooter and e-bike fleet work. Confirm which entity you are dealing with before outreach.
