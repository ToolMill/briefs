E-commerce stack rebuild and internal systems strong signal

Roles: Principal Engineer · PHP Backend Developer · Product Owner - Supply Chain

Requirements mention: monolith · scalable system design · GraphQL · PHP · Nette · forecasting methods · SQL · Python
