What they're building

Platform security for the Operations Cloud strong signal

Roles: Principal Product Manager - Platform Security · Senior Security Engineer - Cloud Security

Requirements mention: zero-trust · hardened multi-tenant isolation architecture · vulnerability and posture tooling · Istio service mesh · KMS-backed key management

Inference: the two Principal Product Manager postings describe owning and building a platform security portfolio. It spans the Identity & Permissions platform, customer-facing security products such as IP Allow list and SCIM, admin experience, and partner security and governance. The cloud security engineer posting covers the internal infrastructure side. This suggests continued investment in identity, permissions and tenant isolation for the Operations Cloud.
